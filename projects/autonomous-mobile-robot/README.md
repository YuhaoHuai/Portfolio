# Autonomous Mobile Robot

An autonomous mobile robot designed to identify its starting side, navigate a constrained arena, collect targets, and deliver them during a timed task.

**Area:** Mechatronics  
**Stage:** Course project; summary available  
**Tools and methods:** PIC32 · Embedded C · Infrared sensing · Event-driven control

## Context

Stanford University, ME218B course project. Role: project leader.

## My contribution

- Led a three-person team through mechanical, electronic, and software integration.
- Developed infrared-based starting-side identification and a mechanism for status indication.
- Programmed sensor handling, motion control, mechanism execution, and task-state management on a PIC32 microcontroller.

## Technical approach

Event-driven embedded software coordinates sensing and actuation while the robot operates under limits on size, budget, battery power, and external intervention.
