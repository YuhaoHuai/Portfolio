# Dynamic Loading Instrument Optimization

An instrumentation project to automate deformation measurement and improve data collection in a laboratory dynamic-loading experiment.

**Area:** Experimental instrumentation  
**Stage:** Research project; summary available  
**Tools and methods:** Arduino · Infrared sensing · CAD · Data acquisition

## Context

University of Wisconsin–Madison, September 2023–June 2024.

## My contribution

- Worked on instrument improvements and automatic measurement.
- Developed an Arduino-based infrared sensing module for deformation measurement and data collection.
- Supported mechanical and electronic integration for the measurement workflow.

## Technical approach

Sensor-based measurement replaces part of the manual reading process and enables an instrumented path from deformation to recorded experimental data.

## Available materials and validation

The CV describes the work, but design files, calibration procedures, and raw measurements have not yet been added. Numerical improvement claims are omitted until supporting records are available.
