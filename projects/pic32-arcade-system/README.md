# PIC32 Embedded Arcade System

An interactive embedded arcade system combining multiple inputs, actuator control, and an LED matrix display.

**Area:** Embedded systems  
**Stage:** Course project; summary available  
**Tools and methods:** PIC32 · Embedded C · LED matrix · Input and actuator integration

## Context

- Integrated actuator control with LED matrix feedback.

A state-based control flow maps player inputs to game behavior, actuator commands, and display updates.
