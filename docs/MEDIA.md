## AI decoration

Only `assets/robotics-concept-ai.jpg` is AI-generated. It is a decorative concept illustration, not a prototype photograph, system diagram, or experimental result. It was created with the built-in imagegen tool and resized/compressed for the portfolio. The existing vector banner remains in the repository as a previous design asset.

### Generation prompt

> Use case: stylized-concept. Asset type: a single restrained decorative editorial illustration for Yuhao Huai's English robotics PhD research portfolio. Generate a wide landscape composition, roughly 3:1 aspect ratio. A quiet, abstract study of robotic perception and tendon-driven mechanics: fine translucent blue-green curves suggesting sensor trajectories, a few precise joint-like geometric elements and delicate taut filaments, arranged as an elegant sculptural composition against a deep navy background matching #0f2339 and #173e50. Soft studio lighting, matte materials, subtle teal highlights, generous breathing room, low visual density, refined academic editorial tone. No text, no letters, no logos, no UI, no charts, no numerical results, no photorealistic finished robot or prototype. Clearly conceptual art rather than an engineering diagram or evidence of an implemented project. One unified illustration, not multiple panels.
